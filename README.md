# Cloud File Storage System

Cloud-based File Storage System built using Spring Boot, AWS S3, and MySQL.

## Technologies Used

- Java
- Spring Boot
- AWS S3
- MySQL
- Spring Data JPA
- Maven
- Postman

## Project Architecture

Postman → Spring Boot → AWS S3
                     ↓
                  MySQL
